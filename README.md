# Train Ticket Reservation System

A ticket reservation application made using java.The application allows user/passenger to reserve tickets and cancel their reservations.The application also allows the admin to create,delete and update the train schedule.

## Tools 
-Netbeans\
-MySQL\
-MySQL connector\
-FlatLaf
